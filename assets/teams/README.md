# Team logos

The PNG files are bundled for offline display in matchup details. No logo download
is performed when Streamlit starts or a matchup is selected.

Source: ESPN image URLs and team colors provided by the nflverse teams dataset,
retrieved on 2026-09-08 with `nflreadpy.load_teams()`.

- Dataset: https://github.com/nflverse/nflverse-data/releases/tag/teams
- Documentation: https://nflreadpy.nflverse.com/api/load_functions/#nflreadpy.load_teams
- `metadata.json` records the original URL and primary color for each team.

Team logos belong to their respective owners. They identify the participating
teams; this project is not affiliated with the NFL or its teams.
